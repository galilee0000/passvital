# PassVital – démo

Démo web mobile : le QR code d’un manchon PassVital ouvre la création de compte et l’écran Identité. Une fois la fiche enregistrée, chaque nouveau scan affiche la fiche d’urgence.

- Page : `index.html` (GitHub Pages)
- Données : Supabase (fonctions `get_card`, `save_card`, `reset_card`)
- Lien d’un manchon : `https://galilee0000.github.io/passvital/?c=PV-7K2Q-9XA`
