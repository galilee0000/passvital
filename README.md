# PassVital – démo

Démo web mobile : le QR code d’un manchon PassVital ouvre la création de compte et l’écran Identité. Une fois la fiche enregistrée, chaque nouveau scan affiche la fiche d’urgence.

- Page : `index.html` (GitHub Pages)
- Données : Supabase (voir `supabase.sql`)
- Lien d’un manchon : `https://galilee0000.github.io/passvital/?m=a7f3k9q2`

La fiche est protégée : la personne qui scanne doit saisir le code inscrit sur le manchon (démo : `PV-7K2Q-9XA`).
